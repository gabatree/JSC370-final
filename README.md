# Weather and Traffic Accidents in Toronto

This project investigates how weather conditions (e.g., temperature, precipitation, visibility) affect the frequency and severity of traffic accidents in Toronto between 2006 and 2023. Accident data was obtained from the Toronto Police Service, and weather data was retrieved from the ERA5 reanalysis archive.

## 🔗 Interactive Website

Explore the full interactive website here:  
https://gabatree.github.io/Weather-traffic-toronto/index.html

The website includes:
- A project overview and downloadable final report
- Three interactive visualizations:
  - Leaflet map of accident hotspots
  - Line chart of monthly accident trends by injury type
  - Interactive bar chart of injury types by weather/light conditions
